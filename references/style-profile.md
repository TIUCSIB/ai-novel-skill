# 仿写画像(Style Profile)

**何时用**:用户提供了喜欢的文本样例(作者自己的旧作或喜欢的作品),希望新书延续该文风时。语料放 `material/style-sample/`(每个样例一个 txt/md)。

## 生成流程

1. **先跑脚本,再通读**(v3.15):语料 ≥2 部时先 `python <技能目录>/scripts/corpus_stats.py <项目>` —— 对 `material/style-sample/` 逐书算句长节奏(中位/σ/短句占比)、对话比、段落节奏、感官配比、标点习惯、4 字口头禅,输出跨书对照表与类型基线;**量化数字以脚本为准,agent 只补脚本测不了的**:对白与动作/心理的穿插模式、比喻的来源域、开章惯用手法与转场方式、情绪表达习惯(直写还是生理替代)。单一样例无跨书基线,脚本照跑(单书画像模式)。
2. **通读语料**,从五个维度合并成画像(脚本数字 + 通读观察):
   - **句法节奏**:句长中位/σ(脚本)、长短句交错模式、段落行数分布、独句成段频率;
   - **对话比**:占比(脚本)、穿插模式、对白轮次长度;
   - **描写密度与感官**:感官配比(脚本)、环境/动作/心理配比、比喻来源域;
   - **词汇指纹**:高频实词、口头禅(脚本 4 字榜 + 人工辨认专名)、标点习惯(脚本)、情绪表达习惯;
   - **章法习惯**:章长分布与章末收尾占比(脚本,语料带章标记时)、开章手法、钩子类型偏好、转场方式。
2. **写 `style/profile.md`**,结构:
   ```markdown
   # 文风画像:<来源描述>
   ## 量化特征(五维,各带数字与例句)
   ## 模仿要点(写正文时遵守,5-8 条,每条可执行)
   ## 避免事项(该文风没有的东西;以及样例本身的毛病,不要一起学)
   ## 对照自查(自检时逐条问自己)
   ```
3. **接线**:`style/voice.md` 顶部加一行"文风画像见 profile.md,冲突时以 profile 为准";黑名单照常独立生效;
4. **校准**:用画像写 1 个测试章(或第一章),与样例并排对比,修正画像中"学得像"与"学岔了"的部分。

## 纪律

- **学结构不抄文字**:画像记录的是统计特征与手法,禁止照搬原句;黑名单与去 AI 味规则照常优先;
- 语料本身有 AI 味或水字毛病,在"避免事项"里显式列出,不要连病一起学;
- **专属锚点要语料干净才替换**:`corpus_stats.py --write-ref <项目>` 会把跨书基线写进 `style/human-ref.json`,style_stats 的"真人参考"随之换成"本书语料基线" —— 但语料的病会一起算进基线,先核对报告的口头禅榜与病项密度(加速副词/比喻/黑话),干净再替换;
- 每卷收官复盘一次:正文与画像的特征值偏了没有(句长/对话比用 corpus_stats 或 style_stats 复算),偏了 → 修画像或修写法,二选一,写明在 voice.md。
