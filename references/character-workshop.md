# 角色工作坊(Character Workshop)

**何时用**:阶段 0 构建主角团时;新 major 配角首次登场前;角色写"平"了需要重挖时。
**流程**:agent 按问题阶梯逐题提问 → 用户作答(或 agent 起草、用户改)→ 沉淀到 `bible/characters.md` + 台账 `voice` 字段。**宁可现场编,不许留空** —— 空着的项目写 30 章后必然工具人化。

## 快速档:20 问(配角/次要角色)

身份职业?年龄外貌?一句话性格?想要什么(表层动机)?为什么想要(深层动机)?害怕什么?有什么秘密?擅长什么?不擅长什么?说话习惯(句长/口头禅/礼貌度)?对主角的态度?对当前局势的态度?有什么.losses(已失去的)?有什么在乎的人?日常在忙什么?会为什么撒谎?被逼到极限会做什么?身体小习惯(摸戒指/抖腿)?与主线的关系(推/阻/旁观)?**与主线无关的小目标**(防工具人,必填)?

## 完整档:80 问(主要角色,分八层)

1. **基本盘(1-10)**:姓名含义、年龄、外貌记忆点、身份、经济状况、社会关系网位置、健康/伤残、住处、日常动线、随身物。
2. **欲望与恐惧(11-20)**:表层想要什么、深层缺什么、最怕失去什么、短期目标、终身目标、愿意为目标付出到什么程度、底线在哪、什么会让TA破底线、成功后的画面、失败的下场。
3. **过去(21-30)**:成长环境、家庭关系、改变TA的关键事件、旧创伤及应激反应、旧恩情及亏欠对象、教育/师承、旧身份烙印、TA在逃避什么、有什么再也不能失去、有没有见不得光的过去。
4. **价值观(31-40)**:如何看待力量/金钱/感情/规则,崇尚什么、鄙视什么,道德灰区在哪,对"牺牲少数"的态度,宗教/信仰,政治立场,对死亡的态度,什么算"活得值得",最看不起哪种人,最尊重哪种人。
5. **人际(41-50)**:建立信任的方式、被背叛过的经历、表达感情的方式、冲突时的行为模式(攻击/冷处理/逃避)、朋友圈构成、敌人构成、对上位者的态度、对下位者的态度、孤独时的行为、需要人时怎么开口。
6. **语言与行为指纹(51-60)**:句长习惯、口头禅、骂人方式、礼貌度、回避的话题、说谎的破绽、紧张的小动作、得意的小动作、思考时的状态、身体语言基调。**方言与流行语(语言落地,见 folk-speech.md)**:TA 的方言区与浓度档(低=只借语序/中=点缀自明词/高=俚语俗语;不说是哪档就是"作者普通话")、TA 具体会说哪几个方言词/口头禅、TA 上一句学会的流行语是什么且什么时候学的(定 TA 的"语言年龄")。
7. **能力与短板(61-70)**:核心能力及来源、能力的代价与限制、技能盲区、学习能力、战斗/解决问题的风格、资源、人脉、运气点、弱点被人利用过吗、短板如何推动剧情。
8. **与主题的关系(71-80)**:TA体现了主题的哪一面、TA与主角互为镜子还是对照、TA的弧光起点与终点、TA会在哪一卷面临自己的"终极选择题"、TA可能的结局(3 种)、TA的秘密何时曝光、TA对终局的立场、删除TA主线是否还成立(若成立→重做)、TA最动人的一句话、TA最坏的一件事。

## 沉淀规则

- 80 问答案不必全文抄进 bible —— 按"写作用得上"提炼成:身份背景 / 目标动机 / 性格与缺陷 / 声音指纹 / 人物弧光 / 秘密与雷点 六块;
- **声音指纹同步到 `ledger/characters.json` 的 `voice` 字段**(章节上下文包会带它);
- 秘密若构成伏笔,登记进 foreshadowing.json;
- 每弧收官时对照审计:该角色的"小目标"推进了吗?没有 → 下一弧给一场戏。
