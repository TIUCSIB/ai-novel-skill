# 机械禁则(style rules)

写完一章后对照本文件自检。这些都是**可机械判定**的规则,与创作偏好无关;黑名单类规则由 `check_ledger.py` 自动扫描。

## 1. 复读分级(对抗自我复读)

长篇最大的敌人是模型复读自己的旧梗。写第 N 章时,对前文的素材/句式/桥段分级处理:

| 距离 | 规则 |
|---|---|
| 最近 2 章(N-1、N-2) | **禁复用**:同样的比喻、句式、情绪描写、场景套路不得再次出现 |
| 3-5 章前 | **必须变形**:相似情节可以呼应,但叙事角度、措辞、结构必须换掉(相似度压到 40% 以下) |
| 6 章前 | 可引用、可呼应,但要有形式变化(直接引用原文片段除外,如信物、誓言) |

实操:动笔前扫一遍最近 3 章正文的高频句式,把它们当作"自己的口头禅"主动避开 —— 上章用过的句式,本章换写法。

## 2. 字数纪律

- 字数落在 `book.json` 的 `words_per_chapter` 区间内;低于下限 85% 视为不合格(脚本报 ERROR)。
- 字数不足时**扩情节,不灌水**:加一个节拍、加一场对手戏、把转述改成现场;不要堆环境描写和心理独白凑字。
- 超上限 50% 以上考虑拆章而不是硬砍(除非该章节奏本来就该快)。

## 3. 开头与结尾

- **章首禁复述前文**:第一段直接进事件,不许"话说/只见/上次说到"式回炉。前情由读者自己衔接,信息靠自然回带。
- **章末三禁**:禁总结("这一夜注定无眠"式)、禁反问收尾("他能否逃过此劫?")、禁抒情升华。用**动作、悬念、期待**收:一句话钩子、半截对话、突转的画面。

## 4. 视角纪律

- 单章单视角为主(第三人称限知或第一人称);换视角必须有空行分节,且一章内不超过 2 个视角。
- **信息控制**:视角人物不知道的事,叙述里不能提前泄露("他不知道的是……"每卷至多 1 次)。读者已知 > 主角已知的落差才是悬念,叙述越权等于烧悬念。
- 配角视角禁止"全知点评"(如"他不知道这将改变他的一生")。

## 5. 禁用清单维护

`style/voice.md` 的 `## 禁用清单` 是唯一黑名单来源,`check_ledger.py` 逐章扫描:

- 默认字面子串匹配;`regex:` 前缀走正则;条目尾部 `[id]` 是规则库标记(解析时自动剥掉,不影响匹配)。
- **清单主体来自分级规则库** `references/rules.json`(159 条,core/standard/wide 三档 × ban/watch 两类;ban 79 / watch 80 —— watch 是"单个合法、频率成病"的词,如仿佛/宛如/瞬间,进黑名单会误伤):`rules_guide.py init-voice <项目>` 一键导入/重建,手工条目不被覆盖;**只有 ban 类入清单**,watch 由 style_stats 判密度。
- 命中后**改写该句**,不是简单删词 —— 黑名单词往往是句式病的症状(如"一丝"+ 抽象名词 = 套装描写),连同句式一起换。
- 写作中发现新的 AI 腔套路:先 `rules_guide.py print` 看手册确认没有同族规则 → 加进 voice.md(用户确认)或直接补进 rules.json(跑 `validate`)。

默认清单(立项时已写入,可增删):一丝 / 一抹 / 不禁 / 仿佛 / 眸中 / 眼底闪过 / 眼中闪过 / 嘴角勾起 / 空气仿佛凝固 / 深吸一口气 / `不是X,而是Y` 句式 / 总结语(总之、毕竟、总的来说)。

## 6. 一致性硬规则(脚本会查,写作时先遵守)

- 台账里 `alive: false` 的角色不得再次出场或说话(回忆/闪回除外,且回忆要标注)。
- `world_rules.json` 与 `bible/rules.md` 的规则不得违背;需要打破规则时,先经用户同意改规则,再写正文。
- 角色不在场时不得知晓其不在场时发生的具体对话内容(信息链要能回溯到 timeline)。
- 伏笔操作必须与章计划一致:计划里说 `plant` 的,正文里必须真的埋了;没计划的临时埋设,记进 analysis 并说明。

## 7. 副词通胀(节奏加速器)——脚本会查

**"瞬间 / 猛地 / 陡然 / 骤然 / 顿时 / 刹那 / 霍然"这类词单独看都合法,病在频率。** 一章里"瞬间"出现六次,说明每一次转折都在靠它加速,没有一次是靠动作本身完成的。它们承担的是"万能转折"的职能 —— 比"然而/与此同时"更隐蔽,因为在中文网文里看起来天经地义。

| 指标 | 警戒线 | 处理 |
|---|---|---|
| 节奏加速副词 | >2.5 次/千字 | 打斗章可放宽至 3.5,文戏不放宽。**删掉加速器,把动作本身写清楚** |
| 章法连接词(然而/与此同时/不知为何) | >1.0 次/千字 | 用空行直接切场景,如"灵木峰。夜。" |
| "在……的瞬间"句式 | >2 处/章 | 万能从句;拆成两个动作,或写"他认出来了" |

**改法禁止同义词替换**:把"瞬间"换成"刹那"、"猛地"换成"陡然",等于没改 —— 病是"这一处没有动作"而不是"用了这个词"。脚本按句式与密度判定,同义替换照样命中。

## 8. 人味意图(正向推荐;按章功能与弧级分布,由盲审核验)

上面全部是禁则。禁则能除掉 AI 味,除不掉"太干净":一本书即使零黑名单、零套话,仍可能通篇没有一个闲笔、角色一次也没失手、对话永远成功 —— 而这三个特征比任何词表都更暴露 AI,且**没有词可以禁**。

所以每章计划写「人味意图」:**按本章功能从四类里推荐 0-3 项**(推进/过渡/高潮/铺垫),正文落实所选项;不取的项目写明豁免理由。**严禁为满足配额擅自加戏**(新增内容先过注水判定一问:删掉它本章是否变差):

1. **非情节功能细节**(原名"无用细节") —— 不直接推动主线,但必须改善**环境质感/人物感受/生活真实感/情绪留白**之一;四样都改善不了的就是凑数,删。连续两章不得同类。
2. **对话失败** —— 打断 / 说一半 / 答非所问 / 说不出话。AI 的对话永远成功,真人的经常失败。
3. **未闭合线头** —— 本章不解释、短期不打算解释的东西,允许永远不回收。
4. **主角代价** —— 实质损失(物质/关系/声誉/信念),不是过场伤。**升级章、打脸章尤其不能只有收获。**

**分布按弧判断,不要求每章全齐** —— 每章凑齐会逼出机械加戏(第三次数钱的手、为失败而失败)。现行规则:章计划按功能推荐;**每弧至少各有 1 处对话失败、1 处未闭合线头、1 处主角代价**(弧细纲规划、弧末审计核验;连续两弧同类全缺 → [必须修改]);高潮/升级/打脸/结算章主角代价必含,文戏/过渡章可由失误、损耗、关系摩擦承担或延后到本弧他章;紧事件章塞闲笔会泄压,允许整章豁免。审校 D7 对照「人味意图」逐项举证,不因缺项直接扣分,但**为凑配额机械加内容的按 [必须修改] 处理**;style_stats 给单章与近 3 章窗口的人味代标(对话失败/受挫代价),代标只提示、不硬扣分。

## 9. 句长、标点与感官(脚本会查)

- **句长**:叙述句长短交错;短句(<12 字)占比 <15%、句长标准差 <8 字 = "通篇一个调";单句 >60 字必须拆;单句逗号 ≥7 个(一逗到底)要断句。化长句的方法是**拆动作**,不是加标点。
- **碎句堆叠(段落级)**:全章短句占比正常,也可能有"普通叙述里连续 5+ 句碎句"的局部病。style_stats 报「普通叙述碎句堆叠」(带段落行号与动作词密度)时,把相邻动作用一两句长句串起来,或把两句并成一句;动手前先人工复核:那是修辞性停顿还是机械断句?**动作高潮段的短句群合法**,不算病 —— 「动作段短句密集」只提示节奏是否单调,不要求改句长。
- **标点**:重复标点(！！/。。。)与半角标点夹汉字是机械错误,出现即改;破折号、省略号 >3 次/千字视为依赖(确有个人风格的在 voice.md 注明,否则收敛)。
- **感官**:非视觉感官(听/嗅/味/体感)<1.0 次/千字 = 全视觉叙事;每章至少两处非视觉细节,情绪优先交给体感与动作。
- **章法与重复**:连续 ≥3 章同型开头/结尾换一种起法;逐字重复句(章内或跨章)必须换写法。
