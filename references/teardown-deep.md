# 拆文对标学习(Teardown)

把一本对标作品拆成**可迁移的机制**,反哺两处:弧规划的模板选型、`style/voice.md` 的节奏要求。

**核心原则:机械索引一次建立后复用;定性拆解靠精读,不复刻原文。** 只迁移抽象机制——结构、节奏、信息释放方式——**不复刻专有设定、角色组合、关键事件链、标志性场面或原句**(借结构不借文字)。

## 分析边界(六条铁律)
1. 只根据可读原文下结论;缺失写"未知"或"文本未明确",不为填字段编事实。
2. 硬事实附章号或 5–15 字定位词;推断标证据等级。
3. 区分**客观发生顺序**与**文本披露顺序**——大伏笔"埋在哪章"和"读者哪章才知道"是两件事。
4. 分开看**事件推进、读者情绪、篇幅安排**;分数不能代替解释。
5. 只迁移机制,不抄设定。
6. 不把结果倒推成人物"早有预谋"(作者后设的伏笔,角色当场未必知道)。

## 一、机械索引(确定性,先跑)
```
python <技能目录>/scripts/teardown.py "{原文.txt|md}" --book "{书名}" [--outdir 拆文库/{书名}]
```
默认 `all` 一次产出(目录默认 `拆文库/{书名}/`,落在扫榜同级或项目 material 外都行):
- **编码归一**:GBK/UTF-16 自动转 UTF-8(不转,后续按行读会乱码)。
- `chapter_index.csv`:按"第N章"切章、剔目录块、校验章号连续/重复/乱序;给每章起始行、结束行、字数。**精读时按这里的行号定位,不重读全文。**
- `节奏.csv`:逐章字数 / 对白占比 / 句数 / 平均句长 / 段落数 / 单句段率——给爽点间隔和文风节奏的量化底。
- `快速预览.md`:黄金三章的开头/结尾原文片段 + 节奏行,供快速判断"这本书值不值得精拆"。

WARN 里"全文<2 万字多半是短篇"只是提示;由导入或用户坚持要按长篇拆的,照常拆。已有索引要重拆某一章:删它的索引行重跑,或换目录——已有摘要不覆盖。

## 二、定性拆解(agent 精读,按需加载对应段)

进入各段时只读对应小节,产物落盘即可跨会话续。原文变了或章号对不上→ 重跑索引。

### Stage 1 黄金三章
读 `chapter_index.csv` 前三章的原文段(按行号),写:
- **开篇钩子**:每章靠什么抓住读者(悬念/危机/反常/代入),标钩子型(式目见 `hooks.md`)。
- **信息释放节奏**:前三章让读者知道多少世界设定、压下了多少——这是"开局不劝退"的关键。
- **主角立人设的第一动作**:他做了什么让读者愿意跟。

### Stage 2 逐章事实(长书分段)
`chapter_index.csv` 全量 + 抽样精读,每章一行事实:章号 / 主要事件 / 出场角色变化 / 伏笔动作(埋/推/收)/ 章末钩子型。几百章的书**分批派子 agent 抽取**(见 `review-rubric.md` 派发模板的用法),主会话不转贴,直接归档。不足够长的书自己逐章读。

### Stage 3 剧情与节奏(对照 arc-library)
- **弧结构**:每卷分几条弧、各用什么模板(对照 `arc-library.md` 13 型)、弧与弧如何钩连。
- **爽点间隔**:大小爽点各隔几章,"抑"的铺垫多长。
- **信息推进**:用 Stage 2 的伏笔动作列,统计大伏笔从埋到收隔几章、中间回响几次。

### Stage 4 角色与设定
- 主要角色的弧光起止、关系网转折点。
- 设定的引入顺序(力量体系/世界观什么时候揭、一次揭多少)。

### Stage 5 报告(输出到 material)
写 `material/teardown-{书名}.md`(覆盖 research-material.md 第三节的手写版;机械指标引用 `拆文库/{书名}/节奏.csv`,不重算):
```md
# 拆书:{书名}({平台}/{字数}/{完本|连载})
## 一句话可借鉴结论
## 弧结构({N} 条弧)
- 弧 1:{用哪个 arc-library 模板} | 第 {a}-{b} 章 | 钩连下一章的方式
## 黄金三章
- 开篇钩子 / 信息释放 / 主角立人设 —— 各一条可迁移做法
## 爽点节奏
- 大爽点间隔 {N} 章 / 小爽点间隔 {N} 章 / 抑的铺垫 {N} 章(引 节奏.csv)
## 信息释放与伏笔
- 大伏笔:埋 {章}→ 回响 {章,章} → 收 {章};读者所知 vs 真相
## 钩子分布
- 抽 10 个章末归类(悬念/危机/反转/期待/选择),统计间隔
## 文风与对白
- 对白占比 {中位} / 平均句长 {中位} / 单句段率(引 节奏.csv);叙述视角与语感一条
## 可偷清单(3-5 条,只借结构不借文字)
1. {手法 + 怎么用在我书里}
```

## 三、与主流程衔接
- **选题回填**:Stage 5 报告落盘后,找同方向的 `选题决策.md`,只回填仍标 `待拆文验证`、且题材匹配的"能爆的原因"——把假设换成拆出来的机制依据。没有推荐选题(只扫了榜)就跳过,不算无效。
- **反哺弧规划**:拆出的弧模板、爽点间隔写进本书 `outline/arc-1.md` 的选型依据。
- **反哺文风**:对白占比/句长/单句段率的中位,作为 `style/voice.md` 节奏要求的参照锚(不是照抄,是定基线)。
- 由 `import-existing.md`(接自己的旧稿)调用时,篇幅已在导入时定好,照常按本流程拆。

## 四、和旧"拆书"的关系
`research-material.md` 第三节的五问手工拆书是**轻量版**;本文档是带机械索引的**完整版**。只想要快版就留在那儿,想要可续跑、可量化、可回填选题的就走本文档。两者产物都落 `material/`,不冲突。
