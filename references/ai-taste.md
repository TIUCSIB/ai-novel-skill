# AI 味对比例句库(AI Taste Pairs)

**用法**:写正文前扫一遍本库找感觉;盲审 D7 对照本库抓套路;每弧收官把本书自己的高频套路(style_stats 口头禅榜)补充进来。
**原则**:对照是"改写示范",不是禁令清单 —— 上下文确实需要时可以破例,但一章之内同一种套路最多出现一次。
**机器可查的部分**已结构化为分级规则库 `references/rules.json`(14 类目、core/standard/wide 三档;工具 `rules_guide.py`,用法见脚本头注)。本文件的对比例句负责"改成什么样",规则库负责"哪里不能写"。

## 九、万能转折:真实的形态是副词,不是连接词

**这是中文网文里最普遍、也最容易被漏掉的一类 AI 味。** 一般说法会列"然而/与此同时/不知为何"——那只是表层;真正承担"万能转折"职能的是**给动作挂加速器**:一句话推进不了,就加个"瞬间/猛地"。

| AI 腔 | 人味 |
|---|---|
| 死士首领如遭雷击,**猛地**喷出数口精血 | 他跪下的时候,膝盖先着地,人还没倒 |
| 塔身**瞬间**绽放出刺目欲盲的烈焰 | 塔身上的漆先起泡,然后一片片卷起来 |
| 他在看清来人面孔的**瞬间**,脸色瞬间由红转煞白 | 他认出是谁了。他把手里的东西放回桌上,放得很轻 |
| **刹那间**,全场落针可闻 | 有人把凳子往后拖了半寸,声音很响 |
| 拳风**骤然**暴涨,**瞬间**笼罩全场 | 他退了半步 —— 不是怕,是那条腿站不住了 |

判定要点:**这些词单独出现都合法,病在频率**。一章里"瞬间"出现六次,说明每一次转折都在靠它加速,没有一次是靠动作本身完成的。改法不是找同义词(瞬间→刹那→转瞬),而是**删掉加速器,把动作本身写清楚** —— 动作写清楚了,本来就快;写不清楚,加十个"瞬间"也快不起来。

| 指标 | 警戒线 | 说明 |
|---|---|---|
| 节奏加速副词(瞬间/猛地/陡然/骤然/顿时/刹那…) | >2.5 次/千字 | 打斗章可放宽至 3.5,文戏不放宽;频率才是病 |
| 章法连接词(然而/与此同时/不知为何/岂料) | >1.0 次/千字 | 用空行直接切场景 |
| "在……的瞬间"句式 | >2 处/章 | 万能从句,一句替掉整段铺陈 |
| 情绪总结(内心充满/难以言喻的情绪) | >2 处/章 | 演完了又总结一遍 |
| 主题总结(这一刻他终于明白…) | >1 处/章 | 章末三禁的变体 |
| 对话后解释(对话 + "眼神中透露出…") | >2 处/章 | 对话已说清,别再用神情词翻译潜台词 |

## 密度警戒线(与 style_stats.py 阈值一致)

| 指标 | 警戒线 | 说明 |
|---|---|---|
| 比喻(像/如同/仿佛/宛如/好似/犹如) | >2.5 次/千字 | 全章 6 个"像"字比喻就该警惕 |
| 感叹号 | >6 个/千字 | 战斗章可放宽,文戏不放宽 |
| 形容词堆砌("XX的XX的XX的") | 全章 >2 处 | 连环修饰是套装描写的前兆 |
| "不是X,而是Y"句式 | 全章 >2 处 | 偶用有力,惯用成腔 |
| 无对话连续长度 | >2500 字 | 文戏也不例外 |
| 连续段落同字开头 | ≥4 段 | 排比腔前兆 |
| 跨章复读率(3-gram 包含率) | 全书两两中位数 × 1.8(不低于 15%) | **不用绝对值** —— 中文长篇实测峰值只有 12%,绝对阈值永远不触发。脚本按本书自身基线自动定标 |
| 叙述句短句占比(<12 字) | <15% | 句长向均值聚集 = AI 的"均匀感";真人长短交错 |
| 句长标准差 | <8 字 | 通篇一个调;紧张处应短句成串 |
| 单句最长 | >60 字 | 长句口条:读一遍,断不开就拆 |
| 单句逗号数 | ≥7 个 | 一逗到底,给句子留出口 |
| 破折号 | >3 次/千字 | 解释癖;个人风格确需在 voice.md 注明后放宽 |
| 省略号 | >3 次/千字 | 留白依赖;把话说完或换动作收 |
| 重复标点(！！、。。。) | 出现即查 | 机械错误,顺手改 |
| 半角标点夹汉字 | 出现即查 | 统一全角 |
| 非视觉感官(听/嗅/味/体感) | <1.0 次/千字 | 全视觉叙事;气味与体感是真人的情报通道(启发式,只报数) |
| 章法同构(跨章开头/结尾同型) | 连续 ≥3 章 | 每章都以清晨起手、都以对话收尾 = 模板感 |
| 逐字重复句(章内/跨章) | 出现 ≥2 次 | 复读自己;与 3-gram 复读率互补的高精度信号 |

## 十、句式之外:句长、标点、感官与章法(统计层能看见的人味)

词和句式之外,还有一层 AI 味藏在**节奏与体感**里,纯统计就能看见:

- **句长节奏**:AI 的句子长度向均值聚集,通篇"一个调";真人长短交错,紧张处短句成串(`style_stats` 报短句占比与句长标准差)。改法不是把所有句子都改短,而是**该短的地方断开** —— 一个长句拆成两三个动作。
- **标点习惯**:省略号留白、破折号解释是两种依赖症;重复标点与半角标点夹汉字是机械错误。真人的标点癖是个人化且一致的 —— 本项目确有需要就在 voice.md 注明后放宽,否则按表执行。
- **感官通道**:AI 九成只写"看见"。真人写气味、声音、触感、冷热疼痒 —— 非视觉感官 <1.0 次/千字就是"全视觉叙事"(启发式词表,只报数不作硬扣分)。
- **章法同构**:单章都对,连章就是模板 —— 每章都以清晨起景、都以对话收尾、都以省略号留白。跨章统计,连续 ≥3 章同型即警告。
- **逐字重复句**:同一句话本章出现两次以上、或与既往章逐字重复(复用"金句")—— 出现即改。

## 黑名单的边界:它会被"改写法"绕过

字面黑名单只能拦原句。实测:禁掉 `嘴角勾起` 之后,产出变成 `勾起一抹` / `唇角微勾`;禁掉 `空气仿佛凝固` 之后,`仿佛` 单独出现 31 次。**换个说法不等于改掉句式。**

所以黑名单必须配两层:

1. **绕行检测**(`taste_audit.py`):规则不命中、但其核心二字语素在大面积出现 → 报"疑似绕行",交人工判定;
2. **句式层规则**(本文件第九节 + `style_stats.py`):按"这个句子在干什么"而不是"用了哪个词"来判 —— 模式匹配比词表难绕。

写作时的正确心态:黑名单不是"不能写这几个词",而是"这几个词暴露的句式病,换个词也还是病"。

## 人味配额:负向拦截的上限

上面全部是**禁则**(不要写什么)。禁则能除掉 AI 味,但除不掉"太干净"——一本书即使零黑名单、零套话,仍然可能通篇没有一个废料、角色一次也没失手、对话永远成功。**这三个特征比任何词表都更能暴露 AI**,而它们没有对应的词可以禁。

所以每章还有四条**正向配额**(写在章计划的「人味配额」里,由盲审 D7 核验):

1. **无用细节** —— 与主线无关、也不埋任何伏笔的细节,只为让世界有厚度;
2. **对话失败** —— 打断 / 说一半 / 答非所问 / 说不出话。AI 的对话永远成功,真人的经常失败;
3. **未闭合线头** —— 本章不解释、短期不打算解释的东西,允许永远不回收;
4. **主角代价** —— 实质损失,不是"受了点伤"式的过场。升级章、打脸章尤其不能只有收获。

这四条里**两条有机械代理**(`style_stats.py` 的「人味代标」行 / `taste_audit.py` 第六节:对话失败、受挫代价,另报沉默回避 —— 对话全成功且无人吃亏的章会直接提示"太干净"),**两条无法机械统计**(无用细节、未闭合线头),必须靠计划先落成具体安排 + 盲审逐项举证。代标只是提示,硬核验归盲审。


## 修订工序:警告清单 → 干净稿

拿到 style_stats / rules_guide scan / 审校的警告清单后,**不要边看边改**,按工序走(借鉴 MuMuAINovel story-deslop 三遍法与 neuro-book llmlint repair-guide):

**Pass 1 去泛化** —— 只处理"说明书式"的句子:情绪直写、神情套装、气氛套话、复述三件套。动作:删或换成 ai-taste.md 对比例句里的具体事实。**禁止同义词替换**(瞬间→刹那 = 没改)。
**Pass 2 去书面化** —— 只处理"腔":加速副词、连接词、对话报幕(闻言/话音刚落)、说教总结语、翻译腔。动作:删掉后整段重读,不通的地方用角色的行为补,不是用更雅的词填。
**Pass 3 回人味** —— 前两道做完稿子容易"干净但死",这一遍做**减法之外的加法**:补非视觉感官(气味/声音/体感)、一处局部身体细节、对话里一次打断或答非所问。对照人味四配额,缺哪项补哪项。

**删/压/换三工序**(每一处的处理选择):能删则删(该句是否推进情节或人物?不推进直接删)→ 删不掉就压(长句拆短、套话压成事实)→ 压不动才换(换成 ai-taste.md 的人味例句句式,而不是换成同义词)。

**改写禁区**:① 只动被警告覆盖的句子,不顺手"优化"别的(防一改全崩);② **对白改写分级**——甲类(有角色声音/伏笔功能)只改叙述标签不改台词,乙类(纯信息传递)可重写台词;改台词前对照该角色声音指纹;③ 章末/章首的警告句改写后必须仍是钩子,不许改成平叙。

**收敛判据**(改完复测,三条全满足才算修完,否则回到 Pass 1):
1. 该章警告数下降(重跑 `style_stats.py --chapter N` 与 `rules_guide.py scan --chapter N`);
2. **未引入新警告**(尤其防 Pass 3 加料加出新的套装句);
3. 字数变化在 ±20% 内(防"以删代改"把一章删成大纲)。

复测通过后进审校;审校仍有 [必须修改] 项,带着整改清单重走对应 Pass,不从头再来。

## 维护纪律

- 盲审 D7 每抓到一个本书新套路 → 补进本库(带原句与改句);
- 本书的"口头禅镜像"(style_stats 全书高频)每弧看一次,把它当**自己写滥的清单**主动避开;
- 学样例文风时(style-profile),样例的毛病也要记进"避免事项",不要连病一起学。
