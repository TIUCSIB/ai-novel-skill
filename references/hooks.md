# 引子与钩子军火库(Hooks)

**何时读**:写章计划时选"开场引子式 + 章末钩子型与强度";每弧规划时排悬念配比;弧末审计时核对实际分布。
(移植自 chinese-novelist-skill 方法论,按本体系改写:钩子信息落章计划字段,分布核验落弧末审计。)

## 一、章首引子七式(开场 50-150 字,给读者"为什么继续读")

章首禁复述前文(style-guide 3)的正向替代 —— 引子是一个**钩住当下**的小单元:

| 式 | 手法 | 例 |
|---|---|---|
| 01 行动中间切入 | 进场晚:直接从冲突的一刻写 | 刀已经架在账房先生脖子上,沈砚还在算那笔差账 |
| 02 异常细节 | 一个不该出现在此处的物件/痕迹 | 丹炉灰里埋着半枚官印的蜡封 |
| 03 对话冲突 | 第一句就是有分歧的话 | "这炉子不能再开了。""是谁给你的胆子来教我？" |
| 04 感官冲击 | 一个强烈的体感开场(优先非视觉) | 腥甜味先至,人声后到 |
| 05 反常识断言 | 角色说出违反本章读者预期的一句话 | 沈砚认定这世上的灵气,和大风没有分别 |
| 06 倒计时/时限 | 开局亮出时间压力 | 天亮前交不上三炉丹,外门名帖就除名 |
| 07 闪前碎片 | 先给结果的一个切片再回叙 | **慎用**:闪出的碎片不得欺骗读者(闪前内容必须与后文一致),每卷至多 2 次 |

纪律:连续两章不用同一式;06 用的时限必须真实兑现或真实失败,不许悄悄蒸发。

## 二、章末钩子十三式

在 craft.md 五型(悬念/危机/反转/期待/选择)基础上扩展:

| # | 型 | 落点 |
|---|---|---|
| 1 | 悬念型 | 发现不该出现的东西 |
| 2 | 危机型 | 追兵/时限/坍塌,倒计时开始 |
| 3 | 反转型 | 刚建立的认知被一句话推翻 |
| 4 | 期待型 | 强者/宝物/比武的预告 |
| 5 | 选择型 | 两难被逼到台前,章末亮出选项 |
| 6 | 情绪型 | 情绪推到顶点处切走(不写宣泄完成) |
| 7 | 信息差型 | 读者比主角多知道一层,章末压着不说破 |
| 8 | 身份危机型 | "他到底是谁"被新证据晃动 |
| 9 | 意象型 | 用前文铺垫 ≥2 次的意象最后一次出现,含义微变 |
| 10 | 回声型 | 末句与本章首句(或上一章首句)近而不同,一字之差埋变化 |
| 11 | 留白型 | 只写反应不写事件:众人看向门口,门口什么都没有——下一章才给门开了 |
| 12 | 承诺型 | 角色当众立约/放话,违约成本已抬满 |
| 13 | 半截对话型 | "其实那晚我看见——"话断在关键处 |

纪律(原有+新增):连续两章不用同型;**10 回声型与 9 意象型的素材必须是前文真实铺垫过的**,临时造的意象钩=空转;11 留白的"未写事件"必须在三章内补给,否则是欺骗不是留白。

## 三、悬念强度五级与波浪配比

每条钩子/开着的线,按"读者要多快知道答案"标强度:

| 级 | 名 | 满足节奏 |
|---|---|---|
| L1 | 微悬念 | 本章内或下一章即解(句级好奇) |
| L2 | 短线 | 2-3 章回收 |
| L3 | 中线 | 5-8 章回收(一个弧的跨度) |
| L4 | 长线 | 跨弧,一卷内解决 |
| L5 | 终极线 | 全书主轴(终极真相/核心身世),挂 compass |

**配比纪律(规划弧时排,弧末审计时核)**:
- 每 20 章应有 2-3 个 **L3+ 高潮锚点**,其余章用 L1-L2 铺谷;峰值间隔 ≤8 章,否则"等待感"堆积成弃书点;
- 任意时刻,**并行开线的合理配置是三弧**:一条短弧(2-3 章内收,给即时满足)+ 一条中弧(5-8 章,当前主冲突)+ 一条长弧(L4/L5,背景推进)——三弧同卷时至少一条在推进,避免"全都没进展"的空转章;
- 章计划的钩子字段写明:型(1-13)+强度(L1-L5)+承接哪条弧;
- 弧末审计新增一步:汇总本弧各章钩子型与强度分布,对照配比;**同型连用、全弧无 L3+ 锚点、三弧全停摆**都在 [必须修正] 之列。

## 四、单章钩子的三段生成法(播种-生长-收获)

设计一条本章钩子的微观节拍(用于章计划写作,约 20/70/10 的篇幅配比):

1. **播种(约 20%)**:把"要悬的东西"混进本章前段的一个正常动作里,一句带过不解释;
2. **生长(约 70%)**:中段让它在错误的时间冒头一次(主角注意到但被打断/误读),张力翻倍;
3. **收获(约 10%)**:章末 1-2 句,让它以最不舒服的角度立住——不给答案,给代价或异样。

反例:只在章末硬贴一个"突然他听见了脚步声"= 无播种的钩子是挂念不是悬念。
