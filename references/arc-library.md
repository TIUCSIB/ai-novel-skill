# 弧线军火库(13 大节奏弧模板)

Architect 规划弧细纲(outline/arc-N.md)时从这里选型。用法:

- 每条弧选 **1 个主模板** 组装节拍,复杂弧可主模板 + 半个辅助模板拼接;
- **相邻两条弧禁用同一模板**;每卷至少安排一条 05 日常过渡弧作呼吸;
- 尊重模板的参考章节规模,超规模 50% 以上说明该拆弧;
- 节拍是骨架,具体桥段结合本项目题材与台账现实填充;
- 来源:作者旧体系(novel-engine)实战验证的模板库,唯物求知型主角尤其适用 06-13。

---

## 01 成长突破弧 (Growth & Breakthrough)

**公式**:瓶颈压抑/危机倒逼 → 另辟蹊径/探索本质 → 艰难验证/多番实验 → 阶跃质变 → 初试锋芒立威。**规模**:6-10 章。
**适用**:玄幻修仙(境界破障)、硬科幻(科技研发)、都市异能(能力觉醒)、末世(基因进阶)。
**核心爽点**:从无解困局中凭智慧与积累完成跃迁,暴涨后的降维掌控感。

- **幕1 瓶颈逼仄(1-2章)**:逼近的危机与硬上限;权威断言"此路不通",主角立足底层原理提出全新突破假设。
- **幕2 筹备推演(3-4章)**:有限条件搜集稀缺要素,展现推演能力;小试受挫,沉着修正参数,期待感拉满。
- **幕3 质变爆发(5-7章)**:突破过程遭遇不可抗力干扰;凭极度冷静的微操逆转险情,完成阶跃式质变。
- **幕4 初露锋芒(8-10章)**:破关而出恰逢敌人以为主角已废前来施压;以全新手段轻描淡写化解,震慑全场。

## 02 竞技对抗弧 (Competition & Tournament)

**公式**:风云汇聚造势 → 初试锋芒 → 针对暗算 → 终极决战底牌尽出 → 登顶名动四方。**规模**:8-14 章。
**适用**:宗门大比、星际对抗赛/黑客攻防、招标竞标/竞技体育、无限流死亡游戏。
**核心爽点**:众目睽睽下名次飙升、打脸自大反派、以弱胜强的精密战术博弈。

- **幕1 造势(1-2章)**:竞争舞台确立,规则与高额战利品公布;反派因出身资历看低主角,立傲慢 Flag。
- **幕2 初战(3-5章)**:一招秒杀叫嚣狂徒;观众由轻视转错愕,敌对势力将主角列为狙击目标。
- **幕3 暗算拆解(6-9章)**:强敌持克制型武器/黑料/规则漏洞,裁判偏袒;主角洞察致命破绽完成反制。
- **幕4 巅峰(10-12章)**:底牌尽出的总碰撞;一击定乾坤,登顶夺冠。
- **幕5 兑现(13-14章)**:当众兑现奖励,赢得敬畏与橄榄枝;败者不甘,引出更大舞台危机。

## 03 探索发现弧 (Exploration & Dungeon)

**公式**:异象现世 → 深入险境破机关 → 同盟反目黄雀在后 → 终极秘藏守护对决 → 崩塌危局全身而退。**规模**:8-15 章。
**适用**:秘境寻宝/古修洞府、废弃空间站/异星遗迹、盗墓地宫、末世避难所探索。
**核心爽点**:未知解密的求知快感、借险恶环境反杀贪婪强敌、独揽世界核心机密。

- **幕1 入场(1-2章)**:神秘地图/异常信号显现,各方势力蠢蠢欲动;主角独立行动或加入心怀鬼胎的队伍。
- **幕2 破障(3-6章)**:致命物理阻碍(辐射/重力畸变/古老阵法/机械陷阱);庸碌之辈死伤惨重,主角以底层规律降维拆解。
- **幕3 内讧(7-9章)**:阶段性宝物现世,同行撕下伪善面具;主角借禁区危险生态反杀贪婪者,反向收割。
- **幕4 守护对决(10-12章)**:直面超规格守卫;避开无敌正面,点中能源中枢或逻辑死角,触碰世界底层真相。
- **幕5 脱身(13-15章)**:夺宝引发崩塌或外敌封锁;经暗道金蝉脱壳,满载而归。

## 04 恩怨冲突弧 (Conflict & Revenge)

**公式**:压迫挑衅 → 收集罪证借势设局 → 绝杀收网 → 连根拔起斩草除根 → 盘点战利威慑四方。**规模**:6-10 章。
**适用**:清算宿仇/反杀世家、商战反击垄断、推翻黑心财阀、谍战拔除内奸。
**核心爽点**:爱憎分明、以牙还牙、将狂妄敌人彻底拉下神坛。

- **幕1 压迫升级(1-2章)**:敌方步步紧逼甚至暗派杀手;主角压制怒火,暗中摸清对方人际网络、底牌与动线。
- **幕2 引蛇出洞(3-4章)**:佯装示弱抛诱饵,迫使敌首底牌尽出踏入死斗圈套;切断其求援通道使其孤立。
- **幕3 雷霆收网(5-7章)**:底牌骤然揭晓,摧枯拉朽反杀;面对求饶绝不圣母,果断摧毁核心首恶。
- **幕4 清算立威(8-10章)**:查抄敌方全部核心资源,消除复仇火种;周边窥探势力震恐,主角坐稳一席之地。

## 05 日常过渡弧 (Daily & Transition)

**公式**:战后清点休整 → 烟火羁绊 → 资产经营基地建设 → 暗流再起新召唤。**规模**:3-6 章。全题材通用。
**核心爽点**:大战后的松弛感、经营收获、人物日常的立体互动。

- **幕1 盘点(1-2章)**:结算战利品与机密;疗伤保养、总结得失,把战斗经验沉淀为本领。
- **幕2 烟火(2-3章)**:与盟友/亲眷/伙伴的轻松交互;展露主角温情一面,强化人格魅力。
- **幕3 经营(3-4章)**:把所获转化为长期产出(升级基地防御、开拓商路、设流水线)。
- **幕4 风起(5-6章)**:远方求援信/加密警报/意外事件打破平静;整理行装奔赴新战场。

## 06 隐忍求知弧 (Endurance & Covert Learning)

**公式**:示弱 → 观察 → 学习 → 试探 → 积累 → 布局 → 暴露一角 → 再次隐藏。**规模**:8-14 章。
**适用**:潜伏敌对大派吸血偷学、黑客潜入财阀盗取机密、卧底渗透、装疯卖傻织反杀网。
**核心爽点**:信息完全不对称的暗中掌控感、抽空敌方底蕴的暗爽、抹平因果的极度冷静。

- **幕1 隐于微末(1-2章)**:主动示弱接下卑微身份;精确测定监控与守卫的注意力死角,确立安全操作空间。
- **幕2 海量学习(3-5章)**:借职权疯狂吞噬核心技术、利益网络与派系矛盾;以无害小动作测试外界警惕性。
- **幕3 暗中布局(6-8章)**:将汲取的知识与自身体系融合完成质变;预留退路,预布嫁祸线索与脱身死穴。
- **幕4 一击归隐(9-12章)**:危机逼临,借环境隐蔽瞬间施展一角恐怖底牌干净灭杀;销毁证据嫁祸第三方,重新潜伏。

## 07 智慧解构弧 (Epistemic Deconstruction)

**公式**:遭遇未知 → 建立假设 → 收集证据 → 实验验证 → 推翻假设 → 找到规律 → 利用规律。**规模**:6-10 章。
**适用**:调查外星黑石碑/破译量子失真信号、破除诅咒规则、破解古修禁地死则、解析未知病毒。
**核心爽点**:硬核求证的理性之美、用实证撕碎神秘与神权、把未知恐惧转化为武器。

- **幕1 黑天鹅(1-2章)**:遭遇超越常识的超常危机,常人陷入恐慌;主角坚守"凡有交互必有守恒律",提出假说 A。
- **幕2 控制变量(3-4章)**:危险边缘设对照组,精密记录参数;数据现悖论,假说被推翻——排除干扰反而摸到核心。
- **幕3 定律诞生(5-7章)**:建立跨维度简化模型,找到混沌数据背后的核心规律;小型验证实验分毫不差,未知被祛魅。
- **幕4 降维破局(8-10章)**:立刻将规律工程化为技术武器;所有人闭目等死之际,主角仅拨动一个参数,死局冰消瓦解。

## 08 藏拙试探弧 (Concealment & Baseline Probing)

**公式**:进入新环境 → 主动藏拙 → 观察强弱 → 找出危险人物 → 测试底线 → 建立安全区 → 暗中积累。**规模**:5-8 章。
**适用**:初入顶级宗门/王侯世家、深空重刑监狱/垄断财阀实验室、派系倾轧的集团、规则不明的死亡游戏。
**核心爽点**:猛兽环伺下从容划定专属安全领域。

- **幕1 制造假面(1-2章)**:踏入弱肉强食的新环境;主动展露"能力中游、老实木讷、毫无油水"的形象,退出竞争焦点。
- **幕2 生态测绘(2-4章)**:冷静评估每个角色:谁是蠢枪、谁是真幕后、谁掌握资源通道;制造一次极小的受控摩擦,测定体制忍受阈值。
- **幕3 安全壁垒(5-6章)**:在章程内申请偏僻的独立空间,建立物理与信息防火墙;对外"遵规而不献媚",形成"招惹此人收益小"的心理防线。
- **幕4 高速积累(7-8章)**:关门全速迭代,消耗积累完成关键突破,为下阶段爆发埋致命伏笔。

## 09 师法偷学弧 (Reverse-Engineering & Synthesis)

**公式**:遇见高手 → 观察 → 模仿 → 失败 → 分析 → 理解原理 → 改造 → 形成自己的体系。**规模**:6-9 章。
**适用**:逆向拆解宗师绝学自创道法、破解顶级黑客协议、生物力学重构必杀技、魔改禁咒。
**核心爽点**:逆向工程的透彻解构、青出于蓝、把天才特权转化为可控技术体系。

- **幕1 生硬照搬(1-2章)**:宗师高光绝技,主角细致记录动作切面与能量轨迹;暗中复刻,因条件不同威力微弱甚至反噬。
- **幕2 直击本质(3-5章)**:拒绝迷信"顿悟/血统/天命",追问底层逻辑;剔除花哨还原为纯粹的力学/能量/算法公式。
- **幕3 定制重构(6-7章)**:结合自身特质修剪原招式缺陷,引入优化参数;以更低能耗更快释放造出独属新技能。
- **幕4 青出于蓝(8-9章)**:与正统传人对决,改良新招全面碾压正宗,主角自立一派体系。

## 10 认知反转弧 (Cognitive Paradigm Shift)

**公式**:原有认知 → 实践 → 发现异常 → 怀疑 → 调查 → 推翻 → 新认知。**规模**:6-10 章。
**适用**:登仙丹实为寄生毒素/飞升实为被收割、跃迁引来捕食者/母体脑控人类、导师实为幕后黑手、丧尸实为意识上传半成品。
**核心爽点**:哥白尼式范式革命、打破思想钢印、细思极恐、从楚门的世界凛然觉醒。

- **幕1 盲信(1-2章)**:世界公认千百年的一项铁律;主角作为体系一员认真循规蹈矩向上攀爬。
- **幕2 裂痕(3-4章)**:精密实践中发现被当作"正常误差"忽略的微小偏差;众人劝"别多想",但一个反例就该让理论大厦坍塌。
- **幕3 抽丝剥茧(5-7章)**:暗设对照实验、翻阅封存档案、测定原始数据;旧认知是人为编织的牢笼与收割谎言,信仰粉碎。
- **幕4 新范式(8-10章)**:毅然斩断旧路自寻破局法;掌握蒙昧者全然不知的世界死穴,蜕变重生。

## 11 规则发现弧 (Rule Discovery)

**公式**:遭遇异常 → 记录现象 → 寻找共同点 → 提出规则 → 验证 → 利用规则。**规模**:6-9 章。
**适用**:怪谈规则/无限流副本、物理法则畸变天体、上古杀阵/因果律领域、自动机关囚笼。
**核心爽点**:从无序恐怖中理出秩序、卡世界逻辑 Bug、借敌人主场规则完成反杀。

- **幕1 无差别死局(1-2章)**:踏入绝地,离奇伤亡爆发;同行歇斯底里,主角强行进入绝对客观的冷酷记录模式。
- **幕2 归纳共性(3-4章)**:记录每次伤亡的坐标、时间戳、生理波动、行动向量;交叉比对提炼出死者的唯一共同交集条件。
- **幕3 探针验证(5-6章)**:把环境定义为冰冷执行的自动化状态机;用石块/探针/诱饵生物做小剂量边界测试,完美验证判据。
- **幕4 借刀杀人(7-9章)**:掌握规则后在致命禁区如履平地;面对追兵不拔一刀,以言语诱导诱敌踩中规则红线,借环境抹杀强敌。

## 12 体系解构弧 (Institutional Disassembly)

**公式**:接受体系 → 学习体系 → 发现矛盾 → 拆解体系 → 找到基础原理 → 重构体系。**规模**:7-11 章。
**适用**:工业化重构传统丹经/炼金术、推翻陈腐学术流派/老旧代码架构、财政模型颠覆式变法、模块化标准颠覆军工。
**核心爽点**:学术与工业维度的降维革命、撕碎行业壁垒、用极简真理让旧权威心服口服。

- **幕1 虚心入门(1-2章)**:直面浩如烟海的古老典籍与祖训;不盲目自大,以极高效率系统吸收前人经验主义积累。
- **幕2 逻辑暴雷(3-4章)**:敏锐抓出传统理论的核心矛盾(甲定律与乙口诀冲突,废品率极高);旧权威避而不谈,靠打补丁维持垄断。
- **幕3 手术拆解(5-7章)**:全盘撕碎仪式与玄学名称;提炼终极底层机理——"三千卷古经不过是三个方程与几个参数的排列组合"。
- **幕4 工业革命(8-11章)**:自创极简新工序,耗时缩短数十倍成本断崖下跌,品质前所未有;铁证面前旧权威崩溃折服,主角成新一代开山宗师。

## 13 失败复盘弧 (Failure & Root-Cause Iteration)

**公式**:失败 → 情绪/损失 → 复盘 → 找到真正原因 → 修正 → 再次尝试 → 成功。**规模**:5-8 章。
**适用**:火箭升空爆炸/核聚变约束破裂、炼宝炸炉/走火入魔、伏击被撕碎/黑天鹅亏损、决赛惨败底牌被看穿。
**核心爽点**:求道者的钢铁心性、极致理性、从失败废墟挖出隐藏王牌的反转。

- **幕1 滑铁卢(1-2章)**:精心筹备后关键一瞬意外崩盘,数月心血毁于一旦;旁观者落井下石,断言彻底完蛋。
- **幕2 止损封存(2-3章)**:斩断自怨自艾——"失败只是现实反馈的客观测量信号";像法医般封锁现场,残渣逐一编号建档。
- **幕3 5-Why 追因(4-5章)**:层层剥笋找到真因;震惊发现失败源于误打误撞揭开了一条隐藏高能反应通路,驾驭好产出暴涨十倍。
- **幕4 王者归来(6-8章)**:重设边界与安全冗余,把偶发事故转化为受控增益;再次出手成品完美出世,嘲讽者彻底失语。
